# Bug 修復報告 - 2025-10-24

## 🐛 問題 1: 司機端費用顯示 0.0000 SUI

### 問題描述
司機在「可接單行程」頁面看到的所有訂單費用都顯示為 `0.0000 SUI`。

### 根本原因
1. **API Schema 缺少欄位**: `TripSummary` 缺少動態定價相關欄位
2. **單位轉換錯誤**: API 返回時錯誤地將 `total_amount` 乘以 1,000,000

**錯誤代碼**：
```python
# backend/app/api/v1/trips.py (舊版)
total_amount=int(trip.total_amount * 1000000) if trip.total_amount else None,
```

**問題分析**：
- 資料庫中 `total_amount` 已經是 **micro SUI** (MIST)
- API 又乘以 1,000,000，導致數值變成 10^15 級別
- 前端除以 10^9 後，得到非常大的數字或 0

### 修復內容

#### 1. 更新 Schema (`backend/app/schemas/trip.py`)
```python
class TripSummary(BaseModel):
    """行程摘要 (用於列表顯示)"""
    trip_id: int
    status: TripStatus
    pickup_address: Optional[str]
    dropoff_address: Optional[str]
    distance_km: Optional[float]
    total_amount: Optional[int]  # micro SUI
    passenger_count: Optional[int] = 1  # 新增
    requested_at: datetime
    completed_at: Optional[datetime]

    # 動態定價資訊 (新增)
    priority: int = 2
    price_type: str = 'standard'
    surge_multiplier: float = 1.0
    surge_reason: Optional[str] = None

    # 關聯信息
    driver_name: Optional[str] = None
    vehicle_model: Optional[str] = None
    vehicle_plate: Optional[str] = None
```

#### 2. 修正 API 返回 (`backend/app/api/v1/trips.py`)
```python
# GET /api/v1/trips/available

for trip in trips:
    summaries.append(TripSummary(
        trip_id=trip.trip_id,
        status=trip.status,
        pickup_address=trip.pickup_address,
        dropoff_address=trip.dropoff_address,
        distance_km=trip.distance_km,
        total_amount=int(trip.total_amount) if trip.total_amount else None,  # ✅ 修正：不再乘以 1,000,000
        passenger_count=trip.passenger_count,  # ✅ 新增
        requested_at=trip.requested_at,
        completed_at=trip.completed_at,
        # ✅ 新增動態定價資訊
        priority=trip.priority,
        price_type=trip.price_type,
        surge_multiplier=trip.surge_multiplier,
        surge_reason=trip.surge_reason
    ))
```

### 預期結果
- 司機端正確顯示費用（例如：`0.0001 SUI`）
- 顯示優先級標籤（⚡快速 / ⏰標準）
- 顯示動態加價資訊（如有）

- 導致重複呼叫 API

### 建議解決方案

#### 方案 1: 檢查 WebSocket 事件處理
```dart
// available_trips_page.dart
void _setupWebSocket() {
  _ws.on('new_trip_available', (data) {
    print('📨 收到新訂單: $data');

    // 避免重複載入
    if (!_isLoading && mounted) {
      _loadAvailableTrips();
    }
  });
}
```

#### 方案 2: 加入載入狀態檢查
```dart
Future<void> _loadAvailableTrips() async {
  if (_isLoading) {
    print('⏳ 正在載入中，跳過重複請求');
    return;  // 避免重複載入
  }

  setState(() => _isLoading = true);

  try {
    final result = await ApiService.getAvailableTrips(limit: 20);
    // ... 處理結果
  } finally {
    setState(() => _isLoading = false);
  }
}
```

#### 方案 3: 禁用自動重建
```dart
@override
Widget build(BuildContext context) {
  return WillPopScope(
    onWillPop: () async {
      _ws.off('new_trip_available');  // 清理監聽器
      return true;
    },
    child: Scaffold(...),
  );
}
```
