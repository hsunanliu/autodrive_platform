## 📋 概述

本文檔設計 AutoDrive Platform 的代幣經濟架構，包括雙代幣模型（治理代幣 + 實用代幣）、激勵機制、經濟循環、以及可持續性設計。

### 核心目標

1. **可持續增長**: 設計自我強化的經濟循環
2. **公平分配**: 獎勵早期貢獻者與活躍用戶
3. **去中心化治理**: 社區驅動的平台決策
4. **價值捕獲**: 代幣價值與平台使用量掛鉤
5. **用戶獲取**: 通過代幣激勵降低 CAC（用戶獲取成本）

## 🎯 雙代幣模型

### Token 1: **DRIVE** (治理代幣)

**性質**: ERC-20 / SUI Native Token
**總供應量**: 1,000,000,000 DRIVE（10 億，固定供應）
**用途**:
1. ✅ **平台治理**: 提案投票、參數調整
2. ✅ **質押獎勵**: 質押獲得協議收入分成
3. ✅ **折扣優惠**: 持有 DRIVE 享受行程費用折扣
4. ✅ **優先權**: 優先匹配、優先客服
5. ✅ **流動性挖礦**: 提供流動性獲得 DRIVE 獎勵

### Token 2: **ADM** (AutoDrive Miles - 實用積分)

**性質**: 鏈上積分，可燃燒但不可轉讓
**供應量**: 無上限（按需鑄造，通過使用燃燒）
**用途**:
1. ✅ **支付費用**: 使用 ADM 支付部分行程費用
2. ✅ **兌換獎勵**: ADM 兌換優惠券、禮品
3. ✅ **升級會員**: 燃燒 ADM 升級到 VIP 會員
4. ✅ **投票權重**: 累計 ADM 增加治理投票權重
5. ✅ **推薦獎勵**: 邀請好友獲得 ADM

**為什麼雙代幣？**

| 代幣 | DRIVE | ADM |
|-----|-------|-----|
| **流通性** | 可自由交易 | 不可轉讓（靈魂綁定） |
| **價值屬性** | 投機 + 實用 | 純實用 |
| **分配方式** | ICO、空投、挖礦 | 行為獎勵 |
| **價格波動** | 高 | 穩定（1 ADM ≈ $0.01） |
| **目標用戶** | 投資者、治理者 | 所有用戶 |

```javascript
→ 優先匹配訂單
```




### ADM 燃燒機制

**目的**: 防止通脹，維持價值

```javascript
// 每次使用 ADM 時自動燃燒一部分
function useADM(amount) {
    uint256 burnAmount = amount * 20 / 100; // 燃燒 20%
    uint256 actualUse = amount - burnAmount;

    burn(msg.sender, burnAmount);
    deduct(msg.sender, actualUse);
}
```

**燃燒統計**（示例）:
```
月燃燒量: 10,000,000 ADM
月發行量: 12,000,000 ADM
淨通脹: +2,000,000 ADM (1.67%)
```

## 🏛️ 治理機制

### DRIVE 持有者權利

#### 1. 提案權

持有 >= 10,000 DRIVE 可發起提案：
- 平台抽成比例調整（現在 10%）
- ADM 獎勵倍數調整
- 新功能開發方向
- 合作夥伴選擇
- 協議升級

#### 2. 投票權

```javascript
投票權重 = DRIVE 持有量 × 持有時間係數

持有時間係數:
- < 1 個月: 0.5x
- 1-3 個月: 1.0x
- 3-6 個月: 1.5x
- >= 6 個月: 2.0x
```

#### 3. 提案流程

```
1. 提案階段（3 天）
   ├─> 提交提案（需要 10,000 DRIVE）
   └─> 社區討論

2. 投票階段（7 天）
   ├─> DRIVE 持有者投票
   └─> 需要 >= 5% 代幣參與

3. 執行階段（14 天）
   ├─> 若通過（>50% 贊成）
   └─> 核心團隊執行

4. 時間鎖（48 小時）
   └─> 重大提案生效前有冷靜期
```

## 🛡️ 風險與緩解措施

### 風險 1: 代幣價格暴跌

**原因**: 大戶拋售、市場恐慌

**緩解措施**:
- ✅ **鎖倉期**: 團隊與投資者代幣鎖定 2-4 年
- ✅ **緊急流動性**: 儲備金購買支撐價格
- ✅ **燃燒加速**: 價格低於某閾值時加速回購燃燒

### 風險 2: ADM 通脹失控

**原因**: 獎勵發放過多，使用率低

**緩解措施**:
- ✅ **動態調整**: 根據燃燒率自動調整獎勵倍數
- ✅ **每日上限**: 限制每日獲取 ADM 上限
- ✅ **增加使用場景**: 更多 ADM 消耗場景

### 風險 3: 治理攻擊

**原因**: 惡意提案、賄選

**緩解措施**:
- ✅ **提案門檻**: 需要 10,000 DRIVE 才能提案
- ✅ **參與門檻**: 需要 >=5% 代幣參與投票才有效
- ✅ **時間鎖**: 重大提案有 48 小時冷靜期
- ✅ **多簽控制**: 關鍵操作需要多簽批准

## 💡 創新機制

### 1. 動態費率調整

根據供需自動調整平台抽成：

```javascript
function calculateFee(supply, demand) {
    if (demand > supply * 1.5) {
        return baseFee * 1.2; // 高需求，增加抽成
    } else if (demand < supply * 0.5) {
        return baseFee * 0.8; // 低需求，減少抽成吸引司機
    }
    return baseFee;
}
```
